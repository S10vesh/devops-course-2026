# Git vs SVN

## 1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
В Git ветка — это просто указатель на коммит (очень лёгкая операция).  
В SVN ветка — это полное копирование директории на сервере, поэтому это медленно и тяжело.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет. SVN — централизованная система, коммит сразу идёт на сервер. Без сети коммит невозможен.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
- Очень большие бинарные файлы (игры, медиа)
- Строгие корпоративные политики и legacy-проекты (банки, госсектор)
- Когда нужна простая модель "один центральный сервер" без распределённой истории
